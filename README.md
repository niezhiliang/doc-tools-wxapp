# PDF 转换小程序

按新版设计重写的微信原生小程序：无第三方运行时依赖，无需安装或构建 npm。

## 页面与流程

首页 → 选择文件 / 图片 → 确认并提交 → 排队 / 转换 → 预览、分享或保存。
底部只有“首页”和“转换记录”。四个页面覆盖全部现有工具与加载、失败、空记录等状态。

- 图片支持微信聊天、相册、拍照，确认页可移除和调整顺序。
- 文件逐个上传，部分上传失败可重试；已经成功上传的部分复用。
- 上传中退出工作页会中止当前上传；任务提交后后台继续处理。
- 未完成任务每 5 秒查询，离开结果页/记录页停止轮询。
- HTTP 和业务失败在页面显示，用户可重试；不使用全局加载弹层。
- 当前免费转换、免费导出，尚未接入广告解锁。

## 开发

用微信开发者工具直接导入此目录。`app.js` 的 `globalData.baseUrl` 配置后端地址，默认 `http://localhost:9876` 仅适合本机开发。真机必须改为可访问的后端地址，并配置小程序服务域名；微信登录凭据配置在后端。

```sh
npm test          # 模拟流程、接口错误、页面事件与模板表达式检查
npm run design   # 使用实际 WXML/WXSS 重新生成设计预览
```

`design/preview.html` 为离线视觉预览，可用浏览器打开。预览和测试目录已从小程序发布包排除。旧页面、组件示例、图片素材及未引用工具已清理。

核心文件：`app.js`（登录）、`utils/service.js`（HTTP）、`utils/file-ui.js`（格式图标）、`app.wxss`（公共视觉样式），以及 `pages` 下四个原生页面。

真机验收见 `RELAUNCH_CHECKLIST.md`，后端部署与队列说明见上级目录的 `TASK_QUEUE.md`。
