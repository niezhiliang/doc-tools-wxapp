# 小程序 UI 重设计

依据用户提供的七张参考图重写：白色 / 浅灰底、蓝紫主按钮、彩色文件图标、单一主要操作。当前使用名称“PDF转换器”。

- 导航：首页、转换记录。仅展示服务端提供的现有转换工具。
- 文档：选工具 → 直接选择微信文件 → 确认文件 → 开始转换。
- 图片：选工具 → 微信 / 相册 / 拍照 → 调整图片顺序 → 开始转换。
- 任务：排队 / 转换中可离开，从记录恢复；仅上传阶段显示真实百分比。
- 结果：文档分享或预览，图片逐页预览、保存；失败可重新选择。
- 免费验证期保持免费导出。广告解锁尚未接入。

## 查看设计

直接用浏览器打开 `preview.html`。15 个页面/状态使用实际 WXML、WXSS 和演示数据生成，含图片排序、排队、成功、失败、空记录和网络异常。画板用于视觉评审，文件选择、分享和后台转换不在 HTML 中执行。

更新模板或样式后运行：

```sh
node doc-tools-wxapp/design/build-preview.cjs
node doc-tools-wxapp/tests/flow.cjs
```

原生代码位于 `pages/index`、`pages/upload`、`pages/result`、`pages/history`；格式图标映射位于 `utils/file-ui.js`，公共样式位于 `app.wxss`。

## 验证范围

已通过微信开发者工具附带的 WXML / WXSS 编译器和 Node 流程检查（选择来源、大小限制、上传失败重试、任务复用、轮询生命周期、结果文件名）。浏览器检查只验证页面布局，不替代微信真机验证。

发布前仍需真机验证：相册/相机隐私授权、图片排序与长列表滚动、断网重试、后台转换完成后恢复、文件预览/分享及保存权限。真实登录和转换依赖已配置的微信凭据及运行中的后端。
